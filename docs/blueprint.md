# **App Name**: YallaNro7

## Core Features:

- Browse Experiences: Displays a list of available experiences with key details.
- Experience Details: Shows comprehensive details about a selected experience, including images, descriptions, and host information.
- Booking Process: Facilitates booking an experience by selecting dates, times, and number of guests.
- Payment Confirmation: Presents a confirmation page after a successful payment.
- My Bookings: Allows users to view their upcoming and past bookings.
- Real-Time Chat: Provides a chat interface for clients to communicate with hosts.

## Style Guidelines:

- Primary color: A vibrant orange (#FF7A00) to convey energy and excitement, reflecting the adventurous spirit of travel and discovery.
- Background color: A light, desaturated orange (#F2E4D6), offering a warm and inviting feel without distracting from the content.
- Accent color: A reddish-orange (#FF5500), drawing the eye for important interactions.
- Headline font: 'Belleza' (sans-serif) for an artistic, high-fashion look that will grab the user's eye; body font: 'Alegreya' (serif).
- Use simple, clear icons to represent different experience categories and actions, ensuring easy navigation and visual understanding.
- Employ a grid-based layout for displaying experiences, ensuring a clean, organized, and visually appealing interface that is easy to navigate.
- Incorporate subtle transitions and animations to enhance user engagement and provide feedback during interactions.
